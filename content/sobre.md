Olá! Eu sou a Leila Algarve. Desenvolvo software desde 2000, quase sempre em Java: cálculo
financeiro, integração entre sistemas, certificação digital e, nos últimos anos, manutenção e
documentação de sistemas legados.

Boa parte do meu trabalho foi entender sistemas que já existiam: reconstruir o que se perdeu,
documentar o que não tinha documentação e pôr testes onde não havia nenhum. Os projetos do
[portfolio](/portfolio/) são pessoais. O trabalho descrito abaixo foi feito em código de
empresas e clientes, que não é público.

## Experiência

### MGN Informática · Consultor em TI II

*jul/2022 – dez/2024 · Rio de Janeiro*

- Fluxos de URA (atendimento telefônico) em Genesys Composer. Recriei arquivos Callflow
  perdidos por engenharia reversa do VXML gerado.
- Pipelines de CI/CD no Azure DevOps para projetos legados em Java com Maven.
- Scripts em JavaScript com testes unitários, consultas SQL em Oracle e acompanhamento de
  deploys em produção.
- Documentação técnica de microsserviços em Java 8 (Spring Boot, RabbitMQ) e de sistemas em
  Visual Basic e VBA. No fim do contrato, documentei também dois sistemas de colegas para
  completar a entrega ao cliente.

### K2 Sistemas · Analista Desenvolvedor Java

*fev/2013 – fev/2020 · Rio de Janeiro*

- **Mercado imobiliário.** Módulo de cálculo financeiro em Java 8 (ZK, PostgreSQL). As
  planilhas usadas para validar os cálculos com o cliente viraram testes JUnit data-driven.
- **Integração com a CETIP** por API proprietária, com mensagens em campos de posição fixa.
  Criei uma ferramenta em HTML e JavaScript que decodifica essas mensagens na hora.
- **Migração de Java 8 para Java 11.** Relatórios novos em JasperReports, otimização de
  consultas SQL e mentoria de um desenvolvedor júnior em pair programming.
- **Prova de conceito** com Cassandra e Hadoop para uma plataforma de vídeos com sistema de
  recomendação.
- **Protótipo em C#** que compilava e carregava, em tempo de execução, scripts escritos pelos
  próprios engenheiros que usavam o sistema.

### M4U · Analista de Sistemas

*mar/2010 – nov/2012 · Rio de Janeiro*

- Manutenção de um sistema de recarga de celulares em JBoss (EJB, Struts, Web Services, JSP,
  SQL Server).
- Automação dos testes de homologação, até então manuais, incluindo a geração e a limpeza da
  massa de dados.

### Contraste Engenharia · Analista de Sistemas Pleno

*mar/2003 – jan/2005 · Rio de Janeiro*

- Integração entre sistemas em Java RMI escrita só a partir da especificação, sem acesso ao
  sistema de destino: testes contra um mock e geração de centenas de classes a partir de uma
  planilha, o que tornava as correções rápidas.
- Implantação presencial no cliente, no México, com toda a comunicação em inglês.
- Projetos em Java, Visual C++ e VBA, porte de sistemas legados e macros em Excel para
  gráficos e análise de dados.

### TÜV SÜD · Engenheiro de Software

*set/2000 – ago/2002 · Munique, Alemanha*

- Sistema em Java para uma Autoridade Certificadora: emissão e gestão de certificados digitais
  de acordo com a legislação alemã de assinatura digital, com modelagem em UML e padrões de
  projeto.
